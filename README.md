### How to Use
1. Download `Sims2_Language_24.bat`
2. **Right-click** → **Run as administrator**
3. Choose number 1-24
4. Restart The Sims 2

**For Steam Legacy Collection (2025)**  
Add to Launch Options: `-l:th` (change `th` to your language code)

### Important
- The script automatically backs up your registry (choose 0 to restore)
- Some languages (Thai, Russian, Chinese, Japanese, Korean, Hebrew, Greek) may need font mods + correct Windows System Locale to display properly
